# LinkDownload updates

Official signed Android APK releases and update metadata for LinkDownload.

Download the latest APK from [Releases](https://github.com/GooGooGii/LinkDownload-Updates/releases/latest).
After installing a version with in-app updates, open Settings → About → Check updates.
Android requires your confirmation to install updates. Install over the existing app; do not uninstall it to update.

This repository contains only release binaries, update metadata, and this notice.
Application source code, signing keys, credentials, and user data are not published here.
Public APK distribution does not grant a source-code or redistribution license.
